GitHub Sync Settings

Configure once — then every "Save to GitHub" commits your edits directly to the repository.
How to create a token:
GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
· Repository access: select only this repository
· Permissions → Repository permissions → Contents: Read and write
· Set expiration to 90 days or 1 year, then replace it here when it expires. The token is stored only in this browser.
Team access: after saving settings, click "Copy team access link" and share it privately (chat/DM). Anyone who opens the link once can edit and save from their own browser. Don't post the link publicly — it contains the access token.
